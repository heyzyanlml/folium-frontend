🌱 FOLIUM: Tu Guía Verde para el Mundo de las Plantas 🌿
¡Hola, amante de las plantas (o futuro amante)! Bienvenido a FOLIUM, una aplicación web hecha con mucho cariño para ayudarte a cuidar de tus verdes compañeras. Ya sea que seas un experto en jardinería o un curioso que quiere empezar a llenar su casa de hojas, FOLIUM está aquí para echarte una mano (o una rama).

¿Qué es FOLIUM? 🤔
FOLIUM es una aplicación web desarrollada con Next.js que permite buscar información sobre plantas para que les des el cuidado que se merecen. ¿No sabes cuánta agua necesita esa suculenta que te regalaron? ¿O si esa planta de interior sobrevivirá en tu habitación oscura? ¡Aquí encontrarás las respuestas!

Además, FOLIUM cuenta con:
- Un blog (en construcción)
- Una sección de FAQ con las preguntas más frecuentes que encontré en internet.

¿Cómo nació FOLIUM? 🌱
La idea de FOLIUM surgió de mi propia experiencia como señora de las plantas primeriza. Aunque amo las plantas, tengo un pequeño problema: soy muy mala cuidándolas. Tan mala, que una vez logré ahogar un cactus. Sí, un cactus. 🌵💦 Después de ese trauma, decidí que necesitaba una herramienta que me ayudara a no cometer más crímenes contra la naturaleza. Así nació FOLIUM, para que tú y yo podamos aprender juntos a ser mejores cuidadores de plantas.

¿Por qué el nombre FOLIUM? 🍃
El nombre del proyecto, FOLIUM, viene del latín y significa "hoja". Porque, al final, todo comienza con una hoja.

¿Cómo funciona? 🛠️
FOLIUM utiliza la API de Perenual para obtener datos sobre plantas y mostrarte la información en tarjetas fáciles de leer. ¿Quieres saber más sobre esa planta que acabas de comprar? Solo búscala y listo.

¿Qué viene después? 🚀
Este proyecto es el MVP (Minimum Viable Product) del Proyecto Final del Bootcamp de Desarrollo Web de Tripleten. Pero, no quiero dejarlo solo así. Estoy trabajando en nuevas features y mejoras, como:
- Calendario para registrar el riego de plantas: Porque a veces nos olvidamos de regarlas (o las regamos demasiado, como yo con mi pobre cactus).
- Quiz interactivo para recomendar la planta ideal.
- Dark Mode.
- Cambiar los estilos a Tailwind (Sobretodo porque quiero aprender un framework de CSS)
- Reemplazar la API actual por una hecha en colaboración con otro developer: Con más información y en español, aunque estamos pensando en soportar español e inglés.
  
Tecnologías utilizadas 🛠️
- Next.js
- CSS Modules
- API de Perenual: Para obtener datos sobre plantas
- Vercel
